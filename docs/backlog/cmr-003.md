# [CMR-003] Show the review of a source file when its .review file is open

**Status**: Open
**Priority**: Medium
**Component**: `src/extension.ts`, `README.md`
**Issue**: #4
**Autonomy**: review-pr

**Summary**:
As a reviewer, I want the review panel to show the threads of `foo.c` when I open `foo.c.review`, so that I can start from the list of changed `.review` files and go to the code with one click on a card.

**Description**:
A review of several files leaves several untracked `.review` files, and these are what I see in the git changes view and in the explorer. When I click one, the panel is empty, because a `.review` file is not reviewable. To see the threads I have to find and open the source file by hand.

With this item, when the active editor is a `.review` file, the panel shows the cards of its source file. The extension loads the source document without showing it and uses it as the current document, so the rest of the panel works as it does today. A click on a card opens the source and selects the anchor, which `reveal` already does for a document with no visible editor.

**Scope Decisions**:
- The `.review` file stays open as plain text. Opening the source instead of the `.review` file would be less code, but the raw file could then no longer be read.
- A `.review` file stays not reviewable for the editor commands. Add Comment and the other right-click commands do nothing inside it, and it gets no decorations. Only the choice of the current document changes.
- The source must pass the same check as today, so the `criticmarkReview.sidecarExtensions` setting still applies.
- If the source file does not exist or fails that check, the panel stays empty, as it does for any file that is not reviewable.
- Accept opens the source first, so that I see the change it makes.
- Loading the source takes time, so the most recently active editor wins if I switch files while it loads.
- VS Code closes a document that has no editor after about three minutes. If the source closes while the panel still shows it, the extension loads it again.
- Out of scope: a list of all open reviews across the workspace.

**Acceptance Criteria**:
- [ ] With `foo.c.review` active, the panel lists the cards of `foo.c`, also when `foo.c` is not open in any editor
- [ ] A click on a card opens `foo.c` and selects the anchor
- [ ] Reply, Edit, Delete and Resolve work from the panel while `foo.c.review` is active
- [ ] Accept opens `foo.c` and applies the change
- [ ] An agent's change to the sidecar on disk appears in the panel while `foo.c.review` is active
- [ ] With a `.review` file whose source is missing or excluded by the setting, the panel is empty and no error is shown
- [ ] `README.md` describes opening a `.review` file
- [ ] All existing tests continue to pass
